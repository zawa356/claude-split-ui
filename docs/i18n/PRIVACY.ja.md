# プライバシー

[English](../PRIVACY.md) · [日本語](PRIVACY.ja.md)

従来のFirefox PoCは、追加のネットワークリクエスト、データ保存、テレメトリー送信を行いません。**利用者自身のブラウザ内**で、同一オリジンの限定されたbootstrap通信を処理し、対象Feature Flagの2種類のフィールドだけを変更します。それ以外の通信はそのまま通します。追加の拡張機能権限は要求しません。

これはソースコード上の動作説明であり、**第三者によるセキュリティ監査ではありません**。MAIN worldはページと実行環境を共有し、Claude側の実装も変化します。コードを確認し、リスクを理解したうえで使用してください。

HAR、APIレスポンス原本、認証情報、Cookie、アカウント識別子、会話内容をIssueやPRへ投稿しないでください。

脆弱性の報告については[SECURITY.md](../../SECURITY.md)をご覧ください。
