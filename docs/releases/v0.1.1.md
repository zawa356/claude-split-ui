# Claude Split UI v0.1.1 — Experimental prerelease

> Unofficial independent project, not affiliated with Anthropic. Compatibility depends on undocumented Claude Web behavior and can change at any time.

## What changed since v0.1.0

- Prepare Firefox Add-ons (AMO) submission with a stable add-on ID and explicit no-data-collection declaration.
- Synchronize extension, package and release artifact versions to 0.1.1.
- Refresh English/Japanese installation, verification, privacy, development and AMO publishing documentation.
- Improve version-consistency checks and GitHub Release packaging.

No change to the core Chat / Cowork flag transformation. The WXT Firefox and Chrome implementations previously passed basic manual split/restore tests. The v0.1.1 version bump itself has not yet been independently retested on a live account.

## Downloads

- `claude-split-ui-0.1.1-firefox.zip`: Firefox MV3 WXT, unsigned temporary developer installation (not an AMO-approved XPI).
- `claude-split-ui-0.1.1-chrome.zip`: Chrome MV3 WXT, unpacked developer installation (not on Chrome Web Store).
- `SHA256SUMS.txt`: checksum list.

Extract the browser ZIP once. Firefox: `about:debugging#/runtime/this-firefox` → Load Temporary Add-on → `manifest.json`. Chrome: `chrome://extensions/` → Developer mode → Load unpacked → select the folder containing `manifest.json`.

After loading, reload `https://claude.ai/new`. To revert, remove the temporary Firefox add-on or disable the Chrome extension and reload Claude. Neither browser store has approved this release.
