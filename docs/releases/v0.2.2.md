# Claude Split UI v0.2.2

> Unofficial independent project, not affiliated with Anthropic. Compatibility depends on undocumented Claude behavior and can change at any time.

Restores the separate **Chat / Cowork** selector in Claude: in Firefox and Chrome through a small extension, and in **Claude Desktop** through the shared [claude-desktop-webext](https://github.com/zawa356/claude-desktop-webext) loader. Claude's own files are never modified.

## What changed since v0.2.1

- The bundled Desktop loader is updated to [claude-desktop-webext v0.2.0](https://github.com/zawa356/claude-desktop-webext/releases/tag/v0.2.0):
  - **Fixed:** on Windows, installing no longer stops with "start Claude once first" when Claude (Microsoft Store / MSIX) keeps its data only in its virtualized folder.
  - **Added:** Claude is found through MSIX registration, the running `claude.exe`, classic installer registry entries and standard locations. If several installations are found, choose one with `install.bat -ClaudePath "<path to claude.exe>"` (Linux: `--claude-path`).
  - `uninstall` now runs the same safety checks as `install` before changing anything.
- README (English and Japanese) and the Desktop README describe installation discovery and `-ClaudePath`.

No change to the Chat / Cowork flag transformation or to the browser extension code.

## Verified

- Loader v0.2.0: automated tests on Windows and Ubuntu; on Windows with Claude 2.31226 (MSIX) and only the virtualized data folder, the read-only `diagnose` now succeeds. Installing with this release and restarting on that machine has **not** been tested yet.
- Classic (non-MSIX) Windows installations: detected, **not tested** on a real machine.
- Claude Desktop 2.31226 (Microsoft Store, Windows 11) with loader v0.1.0 (v0.2.1): split selector after restart, side by side with [claude_ctrl-enter](https://github.com/zawa356/claude_ctrl-enter).
- Firefox and Chrome WXT builds: basic split/restore test passed (v0.1.x). The extension code has not changed since.
- Claude Desktop on Linux: **not tested** (the loader is covered by CI only).
