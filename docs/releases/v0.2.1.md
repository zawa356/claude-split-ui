# Claude Split UI v0.2.1

> Unofficial independent project, not affiliated with Anthropic. Compatibility depends on undocumented Claude behavior and can change at any time.

Restores the separate **Chat / Cowork** selector in Claude: in Firefox and Chrome through a small extension, and in **Claude Desktop** through the shared [claude-desktop-webext](https://github.com/zawa356/claude-desktop-webext) loader. Claude's own files are never modified.

## What changed since v0.2.0

- This is the first **Latest** (non-prerelease) release. Earlier releases were prereleases.
- The bundled Desktop loader is pinned to its first release, [claude-desktop-webext v0.1.0](https://github.com/zawa356/claude-desktop-webext/releases/tag/v0.1.0). Its behavior is unchanged from the one in v0.2.0.
- Documentation refresh, in English and Japanese unless noted:
  - README now links to the latest release.
  - Desktop privacy notes.
  - Development guide: submodule, Desktop packaging and release steps.
  - SECURITY no longer mentions the abandoned ASAR patcher.
  - AMO notes now refer to the current version (English and Japanese) and the reviewer build instructions are updated to match (English).
  - Core and Desktop READMEs, and the validation ladder.

No change to the Chat / Cowork flag transformation or to the extension code.

## Verified

- Claude Desktop 2.31226 (Microsoft Store, Windows 11): the split selector appears after installing and restarting Claude. Removing the extension restores the unified UI. It works side by side with [claude_ctrl-enter](https://github.com/zawa356/claude_ctrl-enter) 0.4.
- Firefox and Chrome WXT builds: basic split/restore test passed (v0.1.x). The extension code has not changed since.
- Claude Desktop on Linux: **not tested** (the loader is covered by CI only).

|---|---|---|
