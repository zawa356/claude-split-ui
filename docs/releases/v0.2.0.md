# Claude Split UI v0.2.0 — Experimental prerelease

> Unofficial independent project, not affiliated with Anthropic. Compatibility depends on undocumented Claude behavior and can change at any time.

## What changed since v0.1.1

- **Claude Desktop support (Windows tested).** A new package, `claude-split-ui-0.2.0-desktop.zip`, installs the Chrome build into Claude Desktop through the [claude-desktop-webext](https://github.com/zawa356/claude-desktop-webext) loader. Claude's own files are not modified. The extension coexists with other tools built on the same loader, such as claude_ctrl-enter ≥ 0.4.
- The ASAR patcher plan was dropped. The Microsoft Store (MSIX) build is signed and its install folder is not writable.
- English and Japanese README and FAQ gained a Desktop quick start. The Desktop investigation is in `docs/research/2026-10-09-desktop-poc.md`.

No change to the Chat / Cowork flag transformation or to the browser extensions' behavior.

## Verified

- Claude Desktop 2.31226 (Microsoft Store, Windows 11, Electron 44.4.3):
  - The split Chat / Cowork selector appeared after installing and restarting Claude.
  - The unified UI returned after removing the extension (tested with a hand-made PoC slot, not yet with the loader's uninstall).
  - claude_ctrl-enter kept working alongside it.
- Claude Desktop on Linux: **not tested** (the loader is covered by CI only).
- Browser builds: unchanged since the v0.1.x manual tests; this version bump was not retested on a live account.

## Downloads

- `claude-split-ui-0.2.0-desktop.zip`: Claude Desktop package.
  - **Windows:** extract it, run `install.bat`, then quit Claude completely (tray icon → Quit) and start it again.
  - **Linux:** run `bash install.sh`, log out and in once, then start Claude.
  - To remove it, run `uninstall.bat` or `uninstall.sh`. `diagnose` is read-only.
- `claude-split-ui-0.2.0-firefox.zip`: Firefox MV3 WXT. Unsigned, for temporary developer installation (not an AMO-approved XPI).
- `claude-split-ui-0.2.0-chrome.zip`: Chrome MV3 WXT. Load it unpacked as a developer extension (not on the Chrome Web Store).
- `SHA256SUMS.txt`: checksum list.
