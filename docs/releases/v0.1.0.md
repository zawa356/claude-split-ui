# Claude Split UI v0.1.0 — Experimental prerelease

> Unofficial independent project; not affiliated with Anthropic. This release modifies a local client-side UI feature flag. It does not grant subscriptions or server-side access, and the upstream implementation may change.

## Included

- `claude-split-ui-0.1.0-firefox.zip` — Firefox MV3 WXT extension (temporary developer installation; **not Mozilla-signed XPI**).
- `claude-split-ui-0.1.0-chrome.zip` — Chrome MV3 WXT extension (developer-mode **Load unpacked**; **not Chrome Web Store signed/distributed**).
- `SHA256SUMS.txt` — SHA-256 checksums for the ZIPs.

## Install

**Firefox**: extract its ZIP, open `about:debugging#/runtime/this-firefox`, select **Load Temporary Add-on**, and choose the extracted `manifest.json`. Temporary add-ons disappear when Firefox restarts.

**Chrome**: extract its ZIP, open `chrome://extensions/`, enable **Developer mode**, choose **Load unpacked**, and select the extracted folder containing `manifest.json`.

Reload `https://claude.ai/new`. The separate Chat / Cowork selector should appear. To revert, remove the temporary Firefox extension or disable the Chrome extension and reload the page.

The Firefox and Chrome WXT builds passed manual split/restore smoke testing, plus GitHub Actions build and synthetic tests. Full feature compatibility and future Claude updates are not guaranteed.
